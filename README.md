# Hands-on 2 - Simple Linear Regression

## Descripcion

Programa desarrollado en C++ para implementar una
regresion lineal simple utilizando el caso Benetton.

## Variables

- Advertising: variable independiente (X)
- Sales: variable dependiente (Y)

## Modelo

Y = Beta0 + Beta1 * X

## Funciones

- Calculo de Beta 0
- Calculo de Beta 1
- Ecuacion de regresion
- Prediccion de Sales
- 5 predicciones mediante terminal
